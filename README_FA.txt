نیم طلا - پروژه اولیه اندروید

این پروژه برای ساخت APK آماده شده است.
ویژگی‌ها:
- نام برنامه: نیم طلا
- نمایش نرخ طلای ۱۸ عیار از ۶ منبع
- بروزرسانی دستی
- نمودار مقایسه‌ای
- بخش تحلیل کوتاه‌مدت

نکته مهم:
ساختار سایت‌های منبع ممکن است تغییر کند و بعضی منابع نرخ را با JavaScript یا ضدربات ارائه کنند.
در این نسخه، دریافت مستقیم صفحه و استخراج نرخ با الگوی متنی انجام می‌شود؛ برای نسخه نهایی بهتر است یک سرویس واسط (API) برای پایدار کردن دریافت نرخ‌ها اضافه شود.

ساخت APK:
فایل .github/workflows/build-apk.yml برای GitHub Actions آماده است و پس از قرار گرفتن پروژه در یک مخزن GitHub، با اجرای workflow فایل APK را می‌سازد.
